# はじめに：GaussianとGaussView

## 1. GaussianとGaussView
**Gaussian**は世界標準の汎用量子化学計算プログラムであり，分子の電子状態を計算してエネルギー，構造，振動数，分子軌道などを求めることができる。
**GaussView**はGaussianのグラフィカルユーザーインターフェース（GUI）であり，次のことができる。

- **分子構造の構築**：マウス操作で分子を組み立てられる。環構造や置換基のテンプレートも用意されている。
- **Gaussian計算の設定と実行**：構造最適化，振動解析，遷移状態探索，各種スペクトル計算などの入力ファイルを作成し，そのまま実行できる。
- **計算結果の可視化と解析**：最適化構造，振動モード，分子軌道，静電ポテンシャルなどをグラフィカルに表示できる。

## 2. Gaussianでできること
- 構造最適化（安定構造，遷移状態）
- 振動解析（IR・ラマンスペクトル，熱力学量）
- 分子軌道・電荷・静電ポテンシャルの解析
- 励起状態計算（UV-visスペクトル）
- 溶媒効果を取り込んだ計算（PCM，SMDなど）
- 化学反応機構の解析（遷移状態，固有反応座標（IRC））

## 3. 計算の流れ
Gaussian計算は，おおむね次の流れで行う。

1. GaussViewで分子構造（初期構造）を作る
2. 計算条件（ジョブの種類，計算手法，基底関数，電荷とスピン多重度など）を設定する
3. 入力ファイル（`.gjf`）を保存してGaussianを実行する
4. 出力ファイル（`.log`）やチェックポイントファイル（`.chk`）をGaussViewで開いて結果を確認する

## 4. 計算の基礎知識
GaussViewで計算を設定するときに選ぶ項目の意味を，簡単に説明する。

### 計算手法：Hartree-Fock法と密度汎関数法（DFT）
量子化学計算では，分子中の電子の状態をSchrödinger方程式の近似解として求める。
- **Hartree-Fock（HF）法**：最も基本的な手法である。電子どうしの相関（電子相関）を含まないため，現在は単独ではほとんど使われない。
- **密度汎関数法（DFT）**：電子密度からエネルギーを求める手法である。HF法と同程度の計算コストで電子相関を取り込めるため，現在の主流になっている。
- **MP2，CCSD(T)など**：HF法に電子相関を加える高精度な手法（post-HF法）である。精度は高いが計算コストが非常に大きい。

### 汎関数
DFTでは，電子の交換相関エネルギーを表す**汎関数**を選ぶ必要がある。汎関数は，近似の段階によって次のように分類される。

| 分類 | 特徴 | 例 |
|---|---|---|
| LDA | 各点の電子密度だけを使う。最も単純 | SVWN（LSDA） |
| GGA | 電子密度の勾配も使う | BLYP，PBE（PBEPBE），B97D |
| meta-GGA | さらに運動エネルギー密度も使う | TPSS，M06L |
| 混成（Hybrid） | HF交換を一定の割合で混ぜる | B3LYP，PBE0（PBE1PBE），M06-2X |
| 長距離補正（Range-separated hybrid） | 電子間の距離に応じてHF交換の割合を変える | CAM-B3LYP，ωB97X，**ωB97X-D** |

- **B3LYP**は最も広く使われてきた汎関数であるが，分散力（ファンデルワールス力）を記述できない，電荷移動を過大評価する，などの欠点がある。
- 分散力の補正には，Grimmの経験的分散力補正（`EmpiricalDispersion=GD3`または`GD3BJ`）を加える方法がある。
- 本章で用いる**ωB97X-D**は，長距離補正と経験的分散力補正の両方を含む汎関数である（Gaussianのキーワードは`wB97XD`）。分子間相互作用やイオンの配位を扱うのに適している。
- どの汎関数を使っても計算コストに大きな差はないが，計算対象によって向き不向きがある。目的の系に近い計算の文献を調べて選ぶことが重要である。

### 基底関数
分子軌道は，原子を中心とした関数（**基底関数**）の組み合わせで表す。基底関数を大きくするほど精度は上がるが，計算コストも大きくなる。
Popleの基底関数`6-311+G(2d,p)`を例に，名前の意味を説明する。

| 表記 | 意味 |
|---|---|
| `6-` | 内殻軌道を6個のガウス関数で表す |
| `311` | 価電子軌道を3つの関数で表す（triple zeta） |
| `+` | 水素以外の原子に**分散関数（diffuse関数）**を加える。アニオン，孤立電子対，分子間相互作用の記述に必要。`++`は水素原子にも加える |
| `(2d,p)` | **分極関数**。水素以外の原子にd関数を2組，水素原子にp関数を1組加える。軌道の変形（分極）を表せるようになる |

`6-311G(d,p)`は`6-311G**`とも書く。有機分子の計算には，少なくとも`6-31G(d)`以上の基底関数が必要である。

主な基底関数を下表にまとめた。

| 系統 | 基底関数 | 適用範囲 | 価電子殻 | 分極関数 | 分散関数 |
|---|---|---|---|---|---|
| Pople | STO-3G | H–Xe | Minimal | `*` | ― |
| Pople | 3-21G | H–Xe | Double zeta | `*`，`**` | `+` |
| Pople | 6-31G | H–Kr | Double zeta | (3df,3pd)まで | `+`，`++` |
| Pople | 6-311G | H–Kr | Triple zeta | (3df,3pd)まで | `+`，`++` |
| Dunning | cc-pVDZ，cc-pVTZ，cc-pVQZ | H–Ar，Ca–Kr | Double/Triple/Quadruple zeta | 定義に含まれる | 接頭語`aug-` |
| Ahlrichs | Def2SVP，Def2TZVP，Def2QZVP | H–La，Hf–Rn | Double/Triple/Quadruple zeta | P，PP | ― |
| ECP | LanL2DZ，SDD | 重元素 | Double zeta | ― | ― |


### ジョブの種類
| ジョブ | キーワード | 内容 |
|---|---|---|
| 一点計算（Energy） | `SP` | 入力した構造のままエネルギーを計算する |
| 構造最適化（Optimization） | `Opt` | エネルギーが極小になる構造を探す |
| 振動計算（Frequency） | `Freq` | 振動数（IRスペクトル）と熱力学量（零点エネルギー，エンタルピー，自由エネルギー）を計算する |
| Opt+Freq | `Opt Freq` | 構造最適化に続けて振動計算を行う。最もよく使う組み合わせ |
| スキャン（Scan） | `Opt=ModRedundant` | 結合長や二面角を少しずつ変えてエネルギー曲線を求める |

- **構造最適化**は，エネルギーが「極小」になる構造を探す計算である。ただし，初期構造の近くの極小（局所安定構造）に落ち着くだけなので，**最も安定な構造が得られる保証はない**。そのため，複数の初期構造から計算する配座探索が必要になる（第3節）。
- **振動計算**は，最適化した構造が本当に極小かどうかを確かめるためにも行う。すべての振動数が正であれば極小（安定構造），虚数の振動数（Gaussianの出力では負の値）が1つあれば遷移状態である。
- 振動計算は，**構造最適化と同じ計算レベルで**行わなければならない。

### 電荷とスピン多重度
計算する分子の**総電荷**と**スピン多重度**（2*S*+1，*S*は全スピン量子数）を指定する必要がある。

| 例 | 電荷 | スピン多重度 |
|---|---|---|
| 中性の閉殻分子（DMCなど） | 0 | 1（一重項） |
| Li<sup>+</sup>，Li<sup>+</sup>-DMC錯体 | +1 | 1（一重項） |
| DMCのカチオンラジカル | +1 | 2（二重項） |
| DMCのアニオンラジカル | −1 | 2（二重項） |

## 5. Gaussianの入力ファイル
GaussViewで作る入力ファイル（`.gjf`）は，次のような構成のテキストファイルである。

```text
%nprocshared=8                 ← Link 0：CPUコア数
%mem=8GB                       ← Link 0：メモリ量
%chk=DMC_cc.chk                ← Link 0：チェックポイントファイル名
#p opt freq wb97xd/6-311+g(2d,p)   ← ルートセクション：計算の指定（#pはAdditional Print）

DMC cis-cis Opt+Freq           ← タイトル（自由記述）

0 1                            ← 電荷とスピン多重度
 C    0.000000    0.000000    0.000000   ← 原子の座標（Å）
 O    ...

                               ← 最後に空行
```

## 6. Gaussianで扱う主なファイル
| ファイル | 拡張子 | 説明 |
|---|---|---|
| 入力ファイル | `.gjf`，`.com` | Gaussianの入力。テキスト形式 |
| 出力ファイル | `.log`，`.out` | 計算結果。テキスト形式 |
| チェックポイントファイル | `.chk` | 波動関数などを含む計算結果。バイナリ形式。分子軌道の描画などに必要 |
| フォーマット済みチェックポイントファイル | `.fchk`，`.fch` | `formchk`で`.chk`をテキストに変換したもの。異なるOS間でやり取りできる |
| Cubeファイル | `.cube`，`.cub` | 分子軌道や電子密度の3次元データ |
